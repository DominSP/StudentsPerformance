# Students Performance Analysis

## Overview

This project analyzes student performance data and presents the results
through spreadsheets, visualizations, and a prediction component.

## Contents

-   `StudentsPerformance(Data Students Performance).csv` --- source
    dataset.
-   `Students_Performance.xlsx` --- spreadsheet analysis.
-   `correlation plot.jpg` --- correlation visualization.
-   `dashboard1.jpg` --- dashboard visualization.
-   `dashboard2.jpg` --- dashboard visualization.
-   `prediction.jpg` --- prediction result visualization.

## Tools

-   Excel
-   CSV data
-   Data analysis
-   Data visualization
-   Correlation analysis
-   Predictive analysis

## Project Focus

The project explores relationships within student performance data and
presents analytical results in a visual form.

## Key Elements

-   Data preparation and exploration
-   Correlation analysis
-   Dashboard creation
-   Prediction analysis
-   Visual presentation of results

## Purpose

This project demonstrates practical data-analysis and visualization
skills using an educational dataset.
